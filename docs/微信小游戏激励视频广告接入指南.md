# 微信小游戏激励视频广告接入指南

> 基于微信官方文档和 Cocos Creator 3.x 实战经验整理

---

## 一、基础概念

### 什么是激励视频广告

激励视频广告是用户**主动观看完整视频**后获得游戏内奖励的广告形式。具有以下特点：

- **原生组件**：由客户端原生图片、文本、视频控件组成
- **层级最高**：会覆盖在 Canvas 之上，无法通过 CSS/z-index 控制
- **全局单例**：`wx.createRewardedVideoAd()` 返回的是全局单例
- **默认隐藏**：创建后默认不可见，需调用 `show()` 显示
- **用户可控关闭**：只有用户点击"关闭广告"按钮才会关闭，开发者无法强制隐藏

### 前置条件

- **流量主资格**：累计独立访客 UV ≥ 500，或满足其他条件
- **广告位创建**：微信公众平台 → 流量主 → 广告管理 → 新建"激励广告"
- **获取 adUnitId**：创建广告位后获得，格式为 `adunit-xxxxxxxxxxxxxxxx`

---

## 二、核心 API

### 1. 创建广告实例

```typescript
const rewardedVideoAd = wx.createRewardedVideoAd({
    adUnitId: 'adunit-xxxxxxxxxxxxxxxx'  // 替换为你的广告位ID
});
```

> ⚠️ **全局单例特性**：多次调用 `wx.createRewardedVideoAd()` 即使传入不同的 `adUnitId`，返回的都是同一个实例。

### 2. 显示广告

```typescript
rewardedVideoAd.show()
    .then(() => console.log('广告显示成功'))
    .catch(err => console.error('广告显示失败', err));
```

### 3. 手动加载广告

```typescript
rewardedVideoAd.load()
    .then(() => console.log('广告加载成功'))
    .catch(err => console.error('广告加载失败', err));
```

> 广告组件会**自动拉取**并更新。创建后会拉取一次，用户关闭后会拉取下一条。调用 `load()` 在自动拉取成功时会直接返回 resolved Promise。

### 4. 监听事件

| 事件 | 说明 | 回调参数 |
|------|------|----------|
| `onLoad(callback)` | 广告加载成功 | 无参数 |
| `onError(callback)` | 广告加载/播放失败 | `{ errCode, errMsg }` |
| `onClose(callback)` | 用户关闭广告 | `{ isEnded: boolean }` |

## 三、完整实现（推荐方案）

### AdManager.ts

```typescript
import { _decorator, Component } from 'cc';
const { ccclass, property } = _decorator;

/**
 * 微信小游戏广告管理器
 * 单例模式，管理激励视频广告的全生命周期
 */
@ccclass('AdManager')
export class AdManager extends Component {
    // 在编辑器中配置广告位ID，或通过 DebugConfig 动态读取
    @property({ tooltip: '激励视频广告位ID' })
    rewardedAdUnitId: string = 'adunit-xxxxxxxxxxxxxxxx';

    private rewardedVideoAd: any = null;
    private _isAdReady: boolean = false;
    private _isLoading: boolean = false;
    private _onRewardCallback: ((success: boolean) => void) | null = null;

    /** 广告是否已就绪（可以展示） */
    get isAdReady(): boolean {
        return this._isAdReady;
    }

    start() {
        this.initRewardedVideoAd();
    }

    /**
     * 初始化激励视频广告
     * 建议在 start 或 onLoad 中提前调用，减少用户等待时间
     */
    private initRewardedVideoAd() {
        // 检查微信环境
        if (typeof wx === 'undefined' || !wx.createRewardedVideoAd) {
            console.warn('[AdManager] 当前环境不支持激励视频广告');
            return;
        }

        try {
            // 创建广告实例（全局单例）
            this.rewardedVideoAd = wx.createRewardedVideoAd({
                adUnitId: this.rewardedAdUnitId
            });

            // 监听加载成功
            this.rewardedVideoAd.onLoad(() => {
                console.log('[AdManager] 激励视频广告加载成功');
                this._isAdReady = true;
                this._isLoading = false;
            });

            // 监听加载失败
            this.rewardedVideoAd.onError((err: any) => {
                console.error('[AdManager] 激励视频广告加载失败:', err);
                this._isAdReady = false;
                this._isLoading = false;
            });

            // 监听用户关闭广告
            this.rewardedVideoAd.onClose((res: any) => {
                console.log('[AdManager] 用户关闭广告, isEnded:', res.isEnded);
                this._isAdReady = false; // 每次关闭后广告实例失效，需要重新加载

                // 判断是否完整观看
                if (res.isEnded) {
                    // 用户看完了广告
                    console.log('[AdManager] 用户看完了广告');
                    this._onRewardCallback?.(true);

                    // 预加载下一条广告
                    this.loadAd();
                } else {
                    // 用户中途关闭
                    console.log('[AdManager] 用户中途关闭了广告，不发放奖励');
                    this._onRewardCallback?.(false);
                }

                this._onRewardCallback = null;
            });

            // 预加载广告
            this.loadAd();

        } catch (e) {
            console.error('[AdManager] 初始化广告失败:', e);
        }
    }

    /**
     * 加载广告
     * 失败时可重试，返回 Promise
     */
    private loadAd(): Promise<void> {
        if (!this.rewardedVideoAd) {
            console.warn('[AdManager] 广告实例未初始化');
            return Promise.reject('广告实例未初始化');
        }

        this._isLoading = true;

        return this.rewardedVideoAd.load()
            .then(() => {
                console.log('[AdManager] 广告加载成功');
                this._isLoading = false;
            })
            .catch((err: any) => {
                console.warn('[AdManager] 广告加载失败，尝试重新加载:', err);
                this._isLoading = false;
                // 可在此处加入重试逻辑
                return Promise.reject(err);
            });
    }

    /**
     * 展示激励视频广告
     * @param onReward 奖励回调，参数为是否完整观看
     * @returns Promise，展示成功或失败
     */
    showRewardedVideoAd(onReward?: (success: boolean) => void): Promise<void> {
        return new Promise((resolve, reject) => {
            if (!this.rewardedVideoAd) {
                console.warn('[AdManager] 广告实例未初始化，无法展示广告');
                reject('广告实例未初始化');
                return;
            }

            // 保存奖励回调
            if (onReward) {
                this._onRewardCallback = onReward;
            }

            // 展示广告
            this.rewardedVideoAd.show()
                .then(() => {
                    console.log('[AdManager] 广告展示成功');
                    resolve();
                })
                .catch((err: any) => {
                    console.warn('[AdManager] 广告展示失败，尝试重新加载:', err);
                    // 展示失败时，尝试重新加载后再展示
                    this.rewardedVideoAd.load()
                        .then(() => {
                            return this.rewardedVideoAd.show();
                        })
                        .then(() => {
                            console.log('[AdManager] 重新加载后广告展示成功');
                            resolve();
                        })
                        .catch((loadErr: any) => {
                            console.error('[AdManager] 重新加载广告也失败了:', loadErr);
                            this._isAdReady = false;
                            this._onRewardCallback = null;
                            reject(loadErr);
                        });
                });
        });
    }

    /**
     * 销毁广告实例（一般在 onDestroy 中调用）
     */
    destroyAd() {
        if (this.rewardedVideoAd) {
            this.rewardedVideoAd.offLoad();
            this.rewardedVideoAd.offError();
            this.rewardedVideoAd.offClose();
            this.rewardedVideoAd = null;
            this._isAdReady = false;
        }
    }

    onDestroy() {
        this.destroyAd();
    }
}
```

## 四、在按钮中调用

### 方式一：在 UpgradeItemCtrl 中调用广告

```typescript
import { _decorator, Component, Node, Button, Label } from 'cc';
import { AdManager } from './AdManager';
import { GameManager } from '../core/GameManager';

const { ccclass, property } = _decorator;

@ccclass('UpgradeItemCtrl')
export class UpgradeItemCtrl extends Component {
    @property({ type: Button })
    adButton: Button | null = null;

    private _adManager: AdManager | null = null;

    onLoad() {
        // 获取 AdManager 实例
        this._adManager = this.getComponentInHierarchy(AdManager);

        // 绑定 AD 按钮事件
        if (this.adButton) {
            this.adButton.node.on(Node.EventType.TOUCH_END, this.onAdClick, this);
        }
    }

    private onAdClick() {
        if (!this._adManager) {
            console.warn('[UpgradeItemCtrl] AdManager 未找到');
            return;
        }

        // 展示激励视频广告
        this._adManager.showRewardedVideoAd((success: boolean) => {
            if (success) {
                // 用户看完了广告，发放奖励
                console.log('[UpgradeItemCtrl] 发放广告升级奖励');
                const gameManager = this.getComponentInHierarchy('GameManager') as any;
                if (gameManager && gameManager.doUpgrade) {
                    gameManager.doUpgrade(this._upgradeType);
                }
            } else {
                // 用户中途关闭，不发放奖励
                console.log('[UpgradeItemCtrl] 用户未看完广告，不发放奖励');
            }
        }).catch((err: any) => {
            console.error('[UpgradeItemCtrl] 广告展示失败:', err);
            // 广告展示失败的处理：提示用户或降级处理
        });
    }

    private getComponentInHierarchy<T extends Component>(type: new (...args: any[]) => T): T | null {
        const scene = this.node.scene;
        if (!scene) return null;
        return scene.getComponentInChildren(type);
    }
}
```

## 五、关键注意事项

### 1. `isEnded` 判断（核心）

```typescript
rewardedVideoAd.onClose((res) => {
    if (res.isEnded) {
        // 用户看完了完整视频 → 发放奖励
        grantReward();
    } else {
        // 用户中途关闭 → 不发放奖励
        console.log('用户未看完广告');
    }
});
```

### 2. 广告展示失败处理

广告可能因为网络、广告池耗尽等原因加载失败。**务必处理 `show().catch()` 并尝试重新加载**：

```typescript
rewardedVideoAd.show()
    .catch(() => {
        // 展示失败，尝试重新加载
        return rewardedVideoAd.load()
            .then(() => rewardedVideoAd.show());
    });
```

### 3. 基础库版本兼容

- **基础库 < 2.0.4**：不支持 `wx.createRewardedVideoAd`，需做兼容处理
- **基础库 >= 2.1.0**：关闭按钮常驻，用户可随时关闭广告，必须检查 `isEnded`

```typescript
if (typeof wx === 'undefined' || !wx.createRewardedVideoAd) {
    console.warn('当前微信版本过低，不支持激励视频广告');
    return;
}
```

### 4. 广告展示频率限制

- 每个用户每天可观看激励视频广告次数**有限**
- 建议在展示广告按钮前先判断广告是否拉取成功（`_isAdReady`）
- 广告未就绪时按钮置灰或隐藏

### 5. 服务端验证（可选）

对于重要奖励（如复活、解锁关卡），建议接入**激励广告服务端验证**：

1. 在微信公众平台开启服务端验证
2. 配置回调 URL、Token、EncodingAESKey
3. 用户看完广告后，微信广告服务端会通知你的服务器
4. 服务端验证通过后下发奖励

> 对于不影响核心进度的小奖励（如少量金币），仅用前端 `onClose` 回调即可。

### 6. 广告关闭后需要重新加载

每次用户关闭广告后，广告实例失效。**必须在 `onClose` 回调中调用 `load()` 预加载下一条**，否则下次 `show()` 会失败。

### 7. 调试环境

- **开发者工具**：会显示"激励视频广告"的占位画面，`isEnded` 恒为 `true`
- **真机测试**：会显示真实广告内容，需完整观看才能触发 `isEnded = true`
- **广告组件调试**：在开发者工具中勾选"不校验合法域名"可调试

## 六、常见错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 1000 | 后端接口调用失败 | 检查网络、广告位ID是否正确 |
| 1001 | 广告拉取失败 | 稍后重试，或检查广告位状态 |
| 1002 | 广告组件正在加载中 | 等待加载完成后再调用 show |
| 1003 | 广告组件正在展示中 | 等待当前广告关闭后再调用 |
| 1004 | 没有合适的广告 | 正常现象，尝试重新加载 |
| 1005 | 后端校验失败 | 检查 adUnitId 是否正确 |
| 1008 | 广告组件已销毁 | 重新创建广告实例 |

## 七、最佳实践总结

1. **提前初始化**：在场景 `onLoad` 或 `start` 中创建广告实例并预加载
2. **单例模式**：全局只维护一个广告实例，避免重复创建
3. **状态管理**：用 `_isAdReady` 标识广告是否就绪，按钮据此显示/置灰
4. **失败重试**：`show()` 失败时自动 `load()` 再 `show()`
5. **及时预加载**：`onClose` 回调中立即调用 `load()` 预加载下一条
6. **环境判断**：始终检查 `wx` 对象是否存在，兼容非微信环境
7. **用户体验**：广告失败时给予友好提示，不阻断用户正常游戏流程
8. **服务端保护**：重要奖励接入服务端验证，防止客户端作弊
