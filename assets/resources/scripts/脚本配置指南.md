# 《先挣一个亿》脚本配置指南

本文档详细说明每个脚本的挂载位置、属性配置和使用方法，**完全对齐 main.scene 实际节点结构**。

---

## 📁 脚本文件结构

```
assets/resources/scripts/
├── core/                           # 核心逻辑（单例模式，无需挂载）
│   ├── PlayerData.ts              # 玩家数据管理
│   ├── GameManager.ts             # 游戏核心管理器
│   └── AudioManager.ts            # 音效管理器
├── ui/                            # UI 控制器（需要挂载到节点）
│   ├── VfxController.ts           # 单个 VFX 特效控制器
│   ├── VfxManager.ts              # VFX + 音效统一管理器
│   ├── CoinController.ts          # 硬币控制器
│   ├── MainUI.ts                  # 主界面控制器
│   ├── UpgradeItemCtrl.ts         # 升级项控制器（用于 UpgradeSection 和 UpgradePage 的升级类项）
│   ├── AutoFlipBuyCtrl.ts         # 自动翻转购买控制器（MainPage/UpgradeSection/auto 专用）
│   ├── SettingPopupCtrl.ts        # 设置弹窗控制器
│   ├── UpgradePageCtrl.ts         # 升级页面控制器（新增）
│   └── StatusPageCtrl.ts          # 状态页面控制器（新增）
├── utils/                         # 工具类（无需挂载）
│   └── NumberFormatter.ts         # 数值格式化工具
├── LoadingCtrl.ts                 # 加载界面控制器
└── MainSceneController.ts         # 主场景入口控制器
```

---

## 🏗️ 场景结构总览

```
Canvas
├── Camera
├── MainPage              ← 主游戏页面
│   ├── bg
│   ├── CoinSection       ← 抛硬币区域
│   ├── UI                ← UI层
│   │   ├── TopSection    ← 顶部（设置按钮、分数、进度条）
│   │   ├── BottomSection ← 底部（升级按钮、状态按钮）
│   │   └── UpgradeSection← MainPage上的3个升级项（value, speed, auto）
│   └── SettingPopup      ← 设置弹窗（初始非激活）
├── UpgradePage           ← 升级页面（8个升级项）
├── StatusPage            ← 状态页面（预测、记录、属性展示）
└── Toast                 ← 提示弹窗（初始非激活）
```

## 🔧 核心逻辑脚本（无需挂载）

### 1. PlayerData.ts
**功能**：管理玩家数据（余额、8种升级项数值和价格、生涯统计、本地存储、每日重置）

**升级项类型（与场景节点名一致）**：

| 类型 | 名称 | 初始值 | 初始价格 | 增长类型 |
|------|------|--------|---------|---------|
| `value` | 面值 | 1 | 5 | 乘法（1.2x） |
| `speed` | 速度 | 5秒 | 5 | 除法（/1.2） |
| `lucky` | 幸运 | 50% | 5 | 乘法（1.2x） |
| `critical` | 暴击率 | 0% | 5 | 乘法（1.2x） |
| `criticalBonus` | 暴击加成 | 0 | 5 | 乘法（1.2x） |
| `pity` | 保底 | 20次 | 5 | 固定递减 |
| `streakBonus` | 连击加成 | 0 | 5 | 乘法（1.2x） |
| `time` | 自动时间 | 10秒 | 5 | 乘法（1.2x） |

---

**功能**：游戏核心逻辑（抛硬币、暴击/连击/保底判定、得分计算、自动翻转）

### 3. AudioManager.ts
**功能**：音效管理（BGM、点击音效等）

## ⚠️ 常见问题

### Q1: 进度条不更新？
- 检查 `MainUI` 是否正确挂载到 `Canvas` 节点
- 确认 `progressBar` 属性拖入的是 `ProgressBar` 组件，不是 Node

### Q2: 点击硬币没有反应？
- 检查 `CoinController` 是否挂载到 `MainPage/CoinSection/Coin` 节点
- 确认 `Coin` 节点有 `UITransform` 组件（用于接收触摸事件）

### Q3: 升级按钮无法点击？
- 检查余额是否足够
- 确认 `upgradeButtonNode` 和 `adButtonNode` 都已配置

### Q4: 页面切换不工作？
- 检查 `MainSceneController` 是否正确配置页面节点引用
- 确认 MainPage、UpgradePage、StatusPage 都在 Canvas 下

### Q5: VFX 特效不播放？
- 检查每个 vfx 节点是否挂载了 `VfxController`
- 检查 `VfxManager` 的 vfx 节点引用是否正确配置
- 确认 vfx 节点上的 Animation 组件有动画剪辑

### Q6: 音效不播放？
- 检查 `VfxManager` 的音效 AudioClip 是否正确拖入
- 确认 `resources/audios` 文件夹中的音频文件存在且格式正确（.mp3）
- 注意：Web 平台需要用户第一次点击后才能播放音频

### Q7: 升级时 VFX 只在一个页面播放？
- 检查 `VfxManager` 中 `MainPage` 和 `UpgradePage` 的 vfx 节点引用是否都配置了
- `value`、`speed` 两个升级项需要在 MainPage 和 UpgradePage 分别配置对应的 vfx 节点

### Q8: MainPage/auto 按钮点击没反应？
- 确认 `UpgradeSection/auto` 挂载的是 `AutoFlipBuyCtrl`，不是 `UpgradeItemCtrl`
- `AutoFlipBuyCtrl` 点击后会扣除余额并启动自动翻转

## 📝 配置顺序建议

1. **先配置 loading.scene**（简单，测试加载流程）
2. **再配置 main.scene**：
   - 先配置所有 vfx 节点的 `VfxController`
   - 再配置 `VfxManager`（vfx + 音效）
   - 再配置 `MainSceneController`（核心入口）
   - 再配置 `CoinController`（核心玩法）
   - 再配置 `MainUI`（数据显示）
   - 再配置 `UpgradeItemCtrl`（UpgradeSection 和 UpgradePage 的升级项）
   - 再配置 `AutoFlipBuyCtrl`（MainPage 自动翻转购买）
   - 再配置 `UpgradePageCtrl`（升级页面）
   - 再配置 `StatusPageCtrl`（状态页面）
   - 最后配置 `SettingPopupCtrl`

配置完成后，在编辑器中运行测试，查看控制台日志确认各模块初始化成功！
