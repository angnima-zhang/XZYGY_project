# 《先挣一个亿》脚本配置指南

本文档详细说明每个脚本的挂载位置、属性配置和使用方法。

---

## 📁 脚本文件结构

```
assets/resources/scripts/
├── core/                           # 核心逻辑（单例模式，无需挂载）
│   ├── PlayerData.ts              # 玩家数据管理
│   ├── GameManager.ts             # 游戏核心管理器
│   └── AudioManager.ts            # 音效管理器
├── ui/                            # UI 控制器（需要挂载到节点）
│   ├── VfxController.ts           # 单个 VFX 特效控制器
│   ├── VfxManager.ts              # VFX + 音效统一管理器
│   ├── CoinController.ts          # 硬币控制器
│   ├── MainUI.ts                  # 主界面控制器
│   ├── UpgradeItemCtrl.ts         # 升级项控制器（仅用于升级类）
│   ├── AutoFlipBuyCtrl.ts         # 自动翻转购买控制器（MainPage/auto 专用）
│   ├── ShopPopupCtrl.ts           # 升级面板控制器
│   ├── SettingPopupCtrl.ts        # 设置弹窗控制器
│   └── StatsPopupCtrl.ts          # 属性面板控制器
├── utils/                         # 工具类（无需挂载）
│   └── NumberFormatter.ts         # 数值格式化工具
├── LoadingCtrl.ts                 # 加载界面控制器
└── MainSceneController.ts         # 主场景入口控制器
```

## 🔧 核心逻辑脚本（无需挂载）

以下脚本使用单例模式，通过代码调用即可，**无需挂载到场景节点**。

### 1. PlayerData.ts
**功能**：管理玩家数据（余额、8种升级项、生涯统计、本地存储、每日重置）

**使用方式**：
```typescript
import { PlayerData } from './core/PlayerData';

const data = PlayerData.getInstance();
data.getBalance();           // 获取余额
data.addBalance(100);        // 增加余额
data.getUpgradeValue('value'); // 获取面值等级
```

---

### 2. GameManager.ts
**功能**：游戏核心逻辑（抛硬币、暴击/连击/保底判定、得分计算、自动翻转）

**使用方式**：
```typescript
import { GameManager } from './core/GameManager';

const gm = GameManager.getInstance();
gm.flipCoin();               // 抛一次硬币
gm.getBalance();             // 获取余额
gm.buyUpgrade('value');      // 购买升级
gm.startAutoFlip();          // 开始自动翻转
```

---

### 3. AudioManager.ts
**功能**：音效管理（BGM、点击、正面、背面、暴击、升级音效）

**使用方式**：
```typescript
import { AudioManager } from './core/AudioManager';

const audio = AudioManager.getInstance();
audio.init();                // 初始化（预加载音频）
audio.playBGM();             // 播放背景音乐
audio.playClick();           // 播放点击音效
audio.playHead();            // 播放正面音效
```

### 5. VfxController.ts
**挂载位置**：**每个 vfx 节点**（共 14 个）

**需要挂载的节点**：
- `pity/vfx`
- `criticalHit/vfx`
- `streak/vfx`
- `autoing/vfx`
- `value/vfx`（MainPage 和 UpgradePage 各有一个）
- `speed/vfx`（MainPage 和 UpgradePage 各有一个）
- `headProb/vfx`
- `critRate/vfx`
- `critBonus/vfx`
- `pity 下的 vfx`（保底升级）
- `streakBonus/vfx`
- `autoDuration/vfx`

**属性配置**：

| 属性名 | 类型 | 拖入节点 | 说明 |
|--------|------|---------|------|
| `animation` | Animation | 当前 vfx 节点上的 Animation 组件 | 帧动画组件 |
| `defaultDuration` | number | - | 默认播放时长（秒），0=播放完整动画 |
| `loop` | boolean | - | 是否循环播放（autoing 设为 true） |

**配置步骤**：
1. 打开 `main.scene`
2. 选中 `pity/vfx` 节点
3. 添加组件 → `VfxController`
4. `animation` 属性 → 拖入 vfx 节点上的 Animation 组件
5. `loop` 属性 → autoing/vfx 勾选，其他不勾选
6. 重复以上步骤，为所有 vfx 节点配置

## ⚠️ 常见问题

### Q1: 进度条不更新？
- 检查 `LoadingCtrl` 是否正确挂载到 `Canvas` 节点
- 确认 `progressBar` 属性拖入的是 `ProgressBar` 组件，不是 Node

### Q2: 点击硬币没有反应？
- 检查 `CoinController` 是否挂载到 `Coin` 节点
- 确认 `Coin` 节点有 `UITransform` 组件（用于接收触摸事件）

### Q3: 升级按钮无法点击？
- 检查余额是否足够
- 确认 `upgradeButtonNode` 和 `adButtonNode` 都已配置

### Q4: 弹窗不显示？
- 检查 `MainSceneController` 是否正确配置弹窗节点引用
- 确认弹窗节点初始状态为 `active = false`

### Q5: VFX 特效不播放？
- 检查每个 vfx 节点是否挂载了 `VfxController`
- 检查 `VfxManager` 的 vfx 节点引用是否正确配置
- 确认 vfx 节点上的 Animation 组件有动画剪辑
- 查看控制台是否有 `[VfxManager] VFX 节点未配置` 或 `未挂载 VfxController` 的警告

### Q6: 音效不播放？
- 检查 `VfxManager` 的音效 AudioClip 是否正确拖入
- 确认 `resources/audios` 文件夹中的音频文件存在且格式正确（.mp3）
- 检查 AudioManager 初始化是否成功
- 注意：Web 平台需要用户第一次点击后才能播放音频

### Q7: 升级时 VFX 只在一个页面播放？
- 检查 `VfxManager` 中 `MainPage` 和 `UpgradePage` 的 vfx 节点引用是否都配置了
- `value`、`speed` 两个升级项需要在 MainPage 和 UpgradePage 分别配置对应的 vfx 节点

### Q8: MainPage/auto 按钮点击没反应？
- 确认 `UpgradeSection/auto` 挂载的是 `AutoFlipBuyCtrl`，不是 `UpgradeItemCtrl`
- `AutoFlipBuyCtrl` 点击后会扣除余额并启动自动翻转

1. **先配置 loading.scene**（简单，测试加载流程）
2. **再配置 main.scene**：
   - 先配置所有 vfx 节点的 `VfxController`
   - 再配置 `VfxManager`（vfx + 音效）
   - 再配置 `MainSceneController`（核心入口）
   - 再配置 `CoinController`（核心玩法）
   - 再配置 `MainUI`（数据显示）
   - 再配置 `UpgradeItemCtrl`（升级系统）
   - 再配置 `AutoFlipBuyCtrl`（MainPage 自动翻转购买）
   - 最后配置三个弹窗控制器

配置完成后，在编辑器中运行测试，查看控制台日志确认各模块初始化成功！
