# 《先挣一个亿》UI 设计规范

## 📱 设计概述

- **平台**: 微信小游戏 (IAA)
- **屏幕方向**: 竖屏
- **设计尺寸**: 375 × 812px (iPhone X 基准)
- **安全区域**: 顶部 44px (状态栏), 底部 34px (Home Indicator)

## ✨ 动效规范

### 1. 硬币翻转动画
```
触发: 点击
动画: rotate 360° × 3-5圈
时长: 0.5s
缓动: ease-out
落地: 轻微弹跳 scale(1.05) → scale(1)
```

### 2. 余额增加效果
```
数字滚动: 0.3s
飘字动画: 
  - 起始: opacity 1, translateY(0), scale(1)
  - 结束: opacity 0, translateY(-80px), scale(1.2)
  - 时长: 1s
  - 缓动: ease-out
```

### 3. 弹窗动画
```
进入: slideUp 0.3s ease-out
退出: slideDown 0.2s ease-in
背景: fadeIn 0.2s
```

### 4. 按钮点击
```
效果: scale(0.95)
时长: 0.1s
```

### 5. 商店按钮出现
```
触发: 余额 >= 5
动画: fadeIn + slideUp
时长: 0.3s
```

## 📋 设计原则

1. **简洁优先**: 界面元素精简，突出核心玩法
2. **视觉层次**: 通过大小、颜色、间距建立清晰层次
3. **即时反馈**: 每次交互都有视觉或触觉反馈
4. **一致性**: 相同功能使用相同视觉语言
5. **可扩展**: 商店等模块预留扩展空间
