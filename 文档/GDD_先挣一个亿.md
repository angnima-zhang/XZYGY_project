## 1. 游戏概述

### 1.1 游戏简介

《先挣一个亿》是一款竖屏休闲增量点击类游戏（Idle Clicker），玩家通过点击硬币进行"抛硬币"赌博，目标是积累余额达到1个亿。游戏融合了简单的概率玩法、商店升级系统和每日重置机制，为玩家提供轻松有趣且富有挑战性的游戏体验。

### 1.2 游戏定位

| 属性 | 内容 |
|------|------|
| **游戏类型** | 增量点击类 (Idle Clicker) + 休闲赌博 |
| **目标平台** | 微信小游戏 (IAA) |
| **屏幕方向** | 竖屏 |
| **目标用户** | 18-45岁，喜欢轻松休闲游戏的玩家 |
| **游戏时长** | 单次5-30分钟，每日可重复游玩 |
| **核心体验** | 数字增长的爽快感 + 概率刺激 + 策略升级 |

### 1.3 核心循环

```
点击硬币 → 获得余额 → 购买升级 → 更快积累 → 达到目标 → 排行榜竞争 → 每日重置 → 再次挑战
```

## 2. 核心玩法

### 2.1 基础机制

#### 2.1.1 硬币系统

**初始状态**：游戏开始时，屏幕中央有一枚面值为1的硬币。

**抛硬币规则**：
- 玩家点击硬币触发抛掷动画
- 硬币旋转后落地，结果随机：正面或背面
- **正面**：获得等于该硬币面值的余额
- **背面**：无效果，不获得余额

#### 2.1.2 概率设定

| 结果 | 概率 | 效果 |
|------|------|------|
| 正面 | 50% | 获得面值金额 |
| 背面 | 50% | 无效果 |

### 2.2 商店系统

#### 2.2.1 购买项定价规则

**面值升级**：
- 本次升级面值 = 已购买次数 + 1
- 价格 = 本次升级面值
- 例如：第1次购买价格=1，第2次购买价格=2，以此类推

**购买硬币**：
- 新硬币面值 = 当前所有硬币的平均面值
- 价格 = 当前硬币面值 × 当前硬币数量
- 最多同时存在 5 个硬币

**自动翻转**：
- 价格：仅支持广告观看
- 效果：自动抛硬币 1 分钟

#### 2.2.2 商店购买项 (V1.0)

| 购买项 | 效果 | 花费方式 |
|--------|------|----------|
| 面值升级 | 所有硬币面值+1 | 余额 / 看广告 |
| 购买硬币 | 增加一枚新硬币（最多5枚） | 余额 / 看广告 |
| 自动翻转 | 自动抛硬币1分钟 | 仅看广告 |

#### 2.2.3 扩展性设计

商店系统设计为可扩展架构，未来可添加：
- **幸运值提升**：增加正面概率
- **暴击系统**：正面时有几率获得多倍奖励
- **连击奖励**：连续正面获得额外加成
- **特殊硬币**：拥有特殊效果的稀有硬币
- **时间加速**：缩短自动翻转间隔
- **保底机制**：连续背面后必出正面

### 2.3 每日重置机制

**重置时间**：北京时间每天 04:00（凌晨4点）

**重置内容**（全部重置）：
- 玩家余额归零
- 硬币数量重置为1
- 硬币面值重置为1
- 升级进度重置（所有购买次数归零）
- 排行榜数据清空（次日重新竞争）

**设计目的**：
- 配合肉鸽玩法：每天商店内容可能不同（未来扩展）
- 玩家每天都有新鲜感
- 每日凌晨4点重置，照顾熬夜玩家

### 2.4 胜利条件

**目标**：玩家余额达到 1亿（100,000,000）

**奖励**：
- 当日游戏成功标记
- 进入当日成功榜单
- 获得成就奖励（可扩展）

## 3. 游戏系统

### 3.1 排行榜系统

#### 3.1.1 排序规则

- **排序依据**：玩家点击次数（抛硬币次数）
- **排序方向**：升序（点击次数越少，排名越高）
- **榜单范围**：当日成功达到1亿的玩家

#### 3.1.2 榜单显示

- 显示前100名玩家
- 显示玩家自己的排名
- 显示玩家昵称、头像、点击次数、达成时间

### 3.2 数据存储

#### 3.2.1 本地存储

- 玩家当前余额
- 硬币数量和面值
- 已购买升级
- 今日点击次数
- 是否已达目标

#### 3.2.2 云端存储（微信云开发）

- 玩家排行榜数据
- 每日重置标记
- 成就数据

### 3.3 广告集成

#### 3.3.1 广告类型

| 广告位 | 类型 | 触发时机 |
|--------|------|----------|
| 激励视频广告 | 激励视频 | 购买商店物品时选择"看广告" |
| 插屏广告 | 插屏 | 自然断点（如进入商店、返回主界面） |
| Banner广告 | Banner | 底部常驻（可选） |

#### 3.3.2 广告策略

- 激励视频：玩家主动选择，奖励丰厚
- 插屏广告：控制频次，避免干扰体验
- Banner广告：谨慎使用，考虑用户体验

## 8. 变现策略

### 8.1 IAA模式（广告变现）

#### 8.1.1 激励视频广告

**触发点**：
- 商店购买选择"看广告免费获得"
- 每日签到奖励翻倍
- 失败后复活/继续

**奖励设计**：
- 看广告 = 花费余额的 50%
- 鼓励玩家选择广告，提高广告观看率

#### 8.1.2 插屏广告

**触发点**：
- 进入商店界面（30秒冷却）
- 返回主界面（60秒冷却）
- 每日重置后首次进入

**控制策略**：
- 严格限制频次，避免用户反感
- 优先展示激励视频，插屏作为补充

### 8.2 变现优化

#### 8.2.1 广告位优化

- A/B测试不同广告位的CTR
- 优化激励视频的奖励感知价值
- 插屏广告时机精细化

#### 8.2.2 留存提升

- 每日重置机制创造回归动力
- 排行榜激发竞争心理
- 成就系统增加长期目标
