# 先挣一个亿 - Cocos Creator 项目

## 项目信息
- 引擎：Cocos Creator 3.8
- 语言：TypeScript
- 目标：微信小游戏

## 使用方法
1. 用 Cocos Creator 3.8 打开此项目
2. 打开 assets/scenes/Main.scene
3. 将 GameEntry 脚本挂载到 Canvas 节点上
4. 开始开发

## 目录结构
```
├── project.json           # 项目配置
├── assets/
│   ├── scenes/           # 场景文件
│   └── scripts/          # 脚本文件
├── settings/             # 项目设置
└── local/                # 本地配置
```
